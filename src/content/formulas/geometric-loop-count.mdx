حلقه‌ای که شمارنده‌اش هر بار در عدد ثابتی ضرب می‌شود:

```
for (i = a; i <= b; i *= k)
```

<Formula
  id="geometric-loop-count"
  latex={"C(a, b, k) = \\lfloor \\log_k(b/a) \\rfloor + 1 \\qquad (a \\geq 1,\\ k \\geq 2)"}
  caption="تعداد اجرای حلقهٔ لگاریتمی"
  usage="از ۱ تا ۱۰۰ با ضربدر ۲ می‌شود ۷ بار: ۱، ۲، ۴، ۸، ۱۶، ۳۲، ۶۴."
/>

مقادیر شمارنده تصاعد هندسی‌اند: <Formula inline latex={"a,\\ ak,\\ ak^2,\\ \\ldots"} />. شرط ادامه <Formula inline latex={"ak^e \\leq b"} /> است، یعنی <Formula inline latex={"e \\leq \\log_k(b/a)"} />. پس بزرگ‌ترین توانِ مجاز کفِ لگاریتم است و به‌علاوهٔ یک (برای خودِ <Formula inline latex={"e = 0"} />) تعداد اجراهاست.
