## تعریف رسمی

<Formula
  id="big-o-definition"
  latex={"f(n) \\in O(g(n)) \\iff \\exists c > 0,\\ n_0 \\geq 0:\\ \\forall n \\geq n_0,\\ f(n) \\leq c \\cdot g(n)"}
  caption="تعریف رسمی اوی بزرگ"
  usage="برای اثبات، یک c و یک n صفر معرفی کن و نامساوی را برای همهٔ nهای بزرگ‌تر چک کن."
/>

معنای نموداری: از نقطهٔ <Formula inline latex={"n_0"} /> به بعد، منحنی <Formula inline latex={"f"} /> هیچ‌وقت از منحنیِ <Formula inline latex={"c \\cdot g"} /> بالاتر نمی‌زند.
