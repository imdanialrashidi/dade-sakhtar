## جمع با یک سطر بازگشت

<Formula
  id="sum-recurrence"
  latex={"S(0) = 0,\\quad S(n) = n + S(n-1)\\ \\ (n \\geq 1)"}
  caption="رابطهٔ بازگشتی جمع صفر تا n"
  usage="برای n مساوی ۵ می‌شود ۱۵؛ معادل بسته‌اش n در n به‌علاوهٔ ۱ دوم است."
/>

حالت پایه صفر است چون جمعِ هیچ‌چیز تهی است. شاخهٔ بازگشتی عدد آخر را جدا می‌کند و بقیه را به فراخوانی کوچک‌تر می‌سپارد. بازکردنش می‌دهد <Formula inline latex={"S(n) = n + (n-1) + \\cdots + 1 + 0"} />، یعنی همان جمع حسابیِ <Formula inline latex={"n(n+1)/2"} />.
