## تعریف رسمی

<Formula
  id="big-omega-definition"
  latex={"f(n) \\in \\Omega(g(n)) \\iff \\exists c > 0,\\ n_0 \\geq 0:\\ \\forall n \\geq n_0,\\ f(n) \\geq c \\cdot g(n)"}
  caption="تعریف رسمی امگا بزرگ"
  usage="برای اثبات، یک c و یک n صفر معرفی کن و نامساوی معکوس را برای همهٔ nهای بزرگ‌تر چک کن."
/>

معنای نموداری: از نقطهٔ <Formula inline latex={"n_0"} /> به بعد، منحنی <Formula inline latex={"f"} /> هیچ‌وقت از منحنیِ <Formula inline latex={"c \\cdot g"} /> پایین‌تر نمی‌آید.
