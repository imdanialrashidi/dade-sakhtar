حلقه‌ای که با گام ثابت جلو می‌رود:

```
for (i = a; i <= b; i += k)
```

<Formula
  id="arithmetic-loop-count"
  latex={"C(a, b, k) = \\left\\lfloor \\frac{b-a}{k} \\right\\rfloor + 1 \\qquad (b \\geq a,\\ k > 0)"}
  caption="تعداد اجرای حلقهٔ گام‌ثابت"
  usage="مثلاً از ۱ تا ۱۰ با گام ۳ می‌شود کف ۹/۳ به‌علاوهٔ ۱ یعنی ۴ بار."
/>

چرا کف (floor)؟ چون آخرین گامِ ناقص شمرده نمی‌شود: وقتی فاصله بر گام بخش‌پذیر نیست، مقصد رد می‌شود و حلقه یک بار کمتر می‌چرخد.
