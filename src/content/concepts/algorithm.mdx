## الگوریتم چیست؟

الگوریتم (Algorithm) دنباله‌ای از گام‌های دقیق است که ورودی می‌گیرد، بعد از تعداد متناهی گام متوقف می‌شود و خروجی می‌دهد.

<Definition term="الگوریتم" alt="Algorithm">
  روشی برای حل مسئله که پنج ویژگی دارد: صفر یا چند ورودی، حداقل یک خروجی، قطعیت، پایان‌پذیری و انجام‌پذیری.
</Definition>

## پنج ویژگی، با یک مثال

فرض کن می‌خواهی دو متغیر را جابه‌جا کنی. سه الگوریتم متفاوت برایش هست:

```
temp = a; a = b; b = temp
```

```
a = a + b; b = a - b; a = a - b
```

```
a = a * b; b = a / b; a = a / b
```

هر سه همان یک مسئله را حل می‌کنند، ولی هزینه و خطرشان فرق دارد: روش اول همیشه امن است؛ روش دوم در عددهای صحیحِ محدود ممکن است سرریز شود؛ روش سوم اگر یکی از عددها صفر باشد می‌شکند (تقسیم بر صفر).

## چرا «دقیق» مهم است؟

قطعیت یعنی هیچ گامی دو برداشت نداشته باشد. «کمی اضافه کن» دستور نیست؛ «یک واحد اضافه کن» دستور است. پایان‌پذیری یعنی بالاخره تمام شود. انجام‌پذیری یعنی هر گام با ابزار ساده، در زمان محدود، عملی باشد.
