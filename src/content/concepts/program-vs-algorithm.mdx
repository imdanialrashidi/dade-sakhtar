## مرز کجاست؟

برنامه (program) پیاده‌سازیِ یک رویه روی ماشین است؛ الگوریتم (algorithm) خودِ رویه است، مستقل از زبان و ماشین.

<Definition term="تفاوت کلیدی" alt="Algorithm vs Program">
  الگوریتم حتماً پایان‌پذیر است؛ برنامه لازم نیست پایان‌پذیر باشد.
</Definition>

## مثال نقض: حلقهٔ سیستم‌عامل

هستهٔ سیستم‌عامل در یک حلقهٔ بی‌پایان می‌چرخد و رویدادها را رسیدگی می‌کند:

```
while (true) {
  event = wait_for_event();
  handle(event);
}
```

این یک برنامهٔ کاملاً درست است، ولی چون عمداً هیچ‌وقت تمام نمی‌شود، الگوریتم به‌حساب نمی‌آید. پایان‌پذیری همان مرزی است که این دو را جدا می‌کند.
