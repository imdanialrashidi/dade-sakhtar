## خودت را صدا بزن، ولی کوچک‌تر

تابع بازگشتی (Recursive Function) تابعی است که در بدنهٔ خودش را صدا می‌زند؛ ولی هر بار با ورودیِ کوچک‌تر، تا بالاخره به جایی برسد که دیگر خودش را صدا نزند.

<Definition term="تابع بازگشتی" alt="Recursive Function">
  تابعی که خودش را (مستقیم یا غیرمستقیم) با ورودیِ کوچک‌تر فراخوانی می‌کند و با یک حالت پایه جلوی فراخوانیِ بی‌پایان را می‌گیرد.
</Definition>

دو نوع دارد: بازگشت مستقیم (Direct Recursion) یعنی تابع مستقیم خودش را صدا بزند؛ بازگشت غیرمستقیم (Indirect Recursion) یعنی تابع اول تابع دوم را صدا بزند و تابع دوم برگردد سراغ تابع اول.

## دو تکهٔ هر تعریف

هر تعریف بازگشتی دو تکه دارد: حالت پایه که جوابِ آماده است و حالت بازگشتی که مسئله را کوچک می‌کند. هر دو را در درس فاکتوریل قدم‌به‌قدم می‌بینی.

```
int f(int n) {
  if (n == 0) return 1;   /* حالت پایه */
  return n * f(n - 1);    /* حالت بازگشتی */
}
```
