## تابع بازگشتی

تابع بازگشتی (Recursive Function) تابعی است که خودش را صدا می‌زند؛ ولی هر بار با ورودیِ کوچک‌تر.

<Definition term="تابع بازگشتی" alt="Recursive Function">
  تابعی که خودش را (مستقیم یا غیرمستقیم) با ورودیِ کوچک‌تر فراخوانی می‌کند و با یک حالت پایه جلوی فراخوانیِ بی‌پایان را می‌گیرد.
</Definition>

بازگشت مستقیم یعنی خودِ تابع خودش را صدا بزند؛ بازگشت غیرمستقیم یعنی از راه یک تابع دوم برگردد سراغ خودش. در هر دو، قانون یکی است: ورودی باید کوچک شود و یک حالت پایه (Base Case) باید زنجیره را تمام کند.

## فاکتوریل: دو سطر که حلقه را کنار می‌گذارند

<Formula
  id="fact-def"
  latex={"f(0) = 1,\\quad f(n) = n \\cdot f(n-1)\\ \\ (n \\geq 1)"}
  caption="تعریف بازگشتی فاکتوریل"
/>

کدش هم همین دو سطر است:

```
int f(int n) {
  if (n == 0) return 1;
  return n * f(n - 1);
}
```

شاخهٔ بازگشتی فقط برای <Formula inline latex={"n \\geq 1"} /> معتبر است. حالت پایه <Formula inline latex={"f(0) = 1"} /> ترمز زنجیره است: بدون آن، هر فراخوانی یکی دیگر می‌سازد و هیچ‌وقت تمام نمی‌شود.

<Misconception
  wrong="حالت پایه اختیاری است؛ تابع بالاخره خودش متوقف می‌شود."
  correct="بدون حالت پایه هیچ فراخوانی تمام نمی‌شود. هر تعریف بازگشتی باید حداقل یک حالت پایه داشته باشد که بدون صدازدن خودش برگردد."
/>

<Confused prerequisites={["recursive-function"]} retry="کد فاکتوریل را با n مساوی ۳ روی کاغذ اجرا کن: اول تا پایه برو، بعد برگرد و ضرب کن">
  اگر زنجیرهٔ فراخوانی گنگ است، فقط همین دو جهت را جدا کن: رفتن (کوچک‌شدنِ n) و برگشتن (ضرب‌شدنِ جواب‌ها).
</Confused>

## جمع‌بندی

در این درس دیدی که:

1. تابع بازگشتی خودش را با ورودی کوچک‌تر صدا می‌زند؛ مستقیم یا غیرمستقیم.
2. هر تعریف دو تکه دارد: حالت پایه که آماده است و حالت بازگشتی که کوچک می‌کند.
3. فاکتوریل ۵ می‌شود ۱۲۰ با زنجیرهٔ <Formula inline latex={"5 \\cdot 4 \\cdot 3 \\cdot 2 \\cdot 1 \\cdot f(0)"} />.
