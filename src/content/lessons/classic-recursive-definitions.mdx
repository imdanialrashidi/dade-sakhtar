پنج مسئلهٔ آشنا را با همان یک الگو حل می‌کنی: یک حالت پایهٔ آماده، یک گامِ کوچک‌کردن. هر کدام را جدا می‌نویسی و بعد ترکیب را کامل ردیابی می‌کنی.

<Prerequisite ids={["recursion-and-factorial"]} />

## جمع صفر تا n

 <Formula
   id="sum-def"
   latex={"S(0) = 0"}
   caption="حالت پایهٔ جمع"
 />

 <Formula
   id="sum-rec"
   latex={"S(n) = n + S(n-1)\\ \\ (n \\geq 1)"}
   caption="شاخهٔ بازگشتی جمع"
 />

```
int S(int n) {
  if (n == 0) return 0;
  return n + S(n - 1);
}
```

شاخهٔ بازگشتی فقط برای <Formula inline latex={"n \\geq 1"} /> معتبر است. ورودی منفی حالت پایه را هیچ‌وقت نمی‌بیند و زنجیره تمام نمی‌شود؛ پس دامنه همین‌جا قاب می‌شود: فقط نامنفی‌ها. بازکردنش می‌دهد <Formula inline latex={"S(5) = 5 + 4 + 3 + 2 + 1 + 0 = 15"} /> که همان <Formula inline latex={"n(n+1)/2"} /> است.

## توان: ضربِ تکراری

 <Formula
   id="pow-def"
   latex={"P(a,0) = 1"}
   caption="حالت پایهٔ توان"
 />

 <Formula
   id="pow-rec"
   latex={"P(a,n) = a \\cdot P(a,n-1)\\ \\ (n \\geq 1)"}
   caption="شاخهٔ بازگشتی توان"
 />

```
int P(int a, int n) {
  if (n == 0) return 1;
  return a * P(a, n - 1);
}
```

حالت پایه از قرارداد ریاضی می‌آید: هر عدد به‌توان صفر ۱ است. برای مثال <Formula inline latex={"P(2,5) = 32"} />: پنج بار ضرب در ۲ روی زنجیرهٔ فراخوانی‌ها.

## ضرب و تقسیم با جمع و تفریقِ تکراری

ضربِ <Formula inline latex={"a \\cdot b"} /> یعنی b بار جمعِ a. پس حالت پایه وقتی است که شمارنده صفر شود:

```
int M(int a, int b) {
  if (b == 0) return 0;
  return a + M(a, b - 1);
}
```

برای مثال <Formula inline latex={"M(3,4) = 3 + 3 + 3 + 3 + 0 = 12"} />. همین ایده با تفریق، خارج‌قسمت و باقیمانده می‌دهد: تا وقتی مقسوم از مقسوم‌علیه کوچک‌تر نشده، یکی کم کن و یک واحد به خارج‌قسمت اضافه کن.

```
#include <utility>

std::pair<int, int> Q(int a, int b) {
  if (a < b) return {0, a};
  auto [q, r] = Q(a - b, b);
  return {q + 1, r};
}
```

پس <Formula inline latex={"Q(7,3) = (2,1)"} /> و <Formula inline latex={"Q(8,4) = (2,0)"} /> و <Formula inline latex={"Q(2,5) = (0,2)"} />. شرطش این است که مقسوم‌علیه مثبت باشد؛ تقسیم بر صفر تعریف نشده است (همان خطری که در روش ضرب‌وتقسیمِ جابه‌جایی دیدی).

## ترکیب با قاعدهٔ پاسکال

 <Formula
   id="binom-def"
   latex={"C(n,0) = C(n,n) = 1"}
   caption="حالت‌های پایهٔ ترکیب"
 />

 <Formula
   id="binom-rec"
   latex={"C(n,m) = C(n-1,m-1) + C(n-1,m)"}
   caption="شاخهٔ پاسکال: جمع دو خانهٔ بالایی"
 />

 <Formula
   id="binom-dom"
   latex={"0 < m < n"}
   caption="دامنهٔ شاخهٔ پاسکال"
 />

اول n (کل مجموعه) می‌آید و بعد m (تعداد انتخاب): <Formula inline latex={"C(n,m)"} /> یعنی «از n شیء، m تا بردار». دو حالت پایه در حاشیه‌های مثلث پاسکال‌اند. شرط اعتبار: <Formula inline latex={"0 \\leq m \\leq n"} />.

## جمع‌بندی

در این درس دیدی که:

1. جمع و توان و ضرب و تقسیم، هر کدام یک حالت پایه و یک گام کوچک‌کردن دارند.
2. دامنه‌ها قاب‌اند: جمع برای نامنفی‌ها، توان برای نمای نامنفی، تقسیم برای مقسوم‌علیهٔ مثبت.
3. ترکیب با قاعدهٔ پاسکال حساب می‌شود و <Formula inline latex={"C(4,2) = 6"} /> با ترتیبِ «اول n، بعد m».
